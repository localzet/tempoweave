# Security Policy

## Секреты

Kimai token и Jira token хранятся только в SQLite как бинарный результат `safeStorage.encryptString()`. JSON-экспорт их не включает.

Если системное шифрование недоступно, TempoWeave отказывается сохранять токен вместо записи открытого текста. На Linux backend Electron `basic_text` также отклоняется: для токенов нужен работающий Secret Service/KWallet.

## Renderer isolation

- `contextIsolation: true`
- `nodeIntegration: false`
- `sandbox: true`
- Content Security Policy
- запрет открытия дочерних окон
- внешние HTTP(S)-ссылки передаются системному браузеру

## Сеть

Запросы выполняются только main process. Для Kimai следует использовать HTTPS. TempoWeave не отключает проверку TLS-сертификатов. Импорт чека по ссылке разрешён только через HTTPS с точного домена `nalog.ru` или его поддоменов; редиректы запрещены.

## Резервные копии

SQLite backup содержит зашифрованные секреты. Храните его как конфиденциальный файл. JSON export секреты не содержит, но включает коммерческие данные, суммы и описания работ.

## Сообщение об уязвимости

Не публикуйте токены и реальные чеки в issue. Приложите минимальный воспроизводимый пример с обезличенными данными.
