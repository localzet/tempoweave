# Contributing

1. Создайте ветку от `main`.
2. Сохраните отсутствие runtime-зависимостей, если задачу можно решить стандартной библиотекой.
3. Добавьте тест для изменений финансовой логики, дедупликации или графиков.
4. Выполните `npm run check`.
5. Не добавляйте реальные токены, URL приватных Jira/Kimai и данные чеков.
